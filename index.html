What is the Shortcut Virus?

🦠
Understanding the Threat
USB / Removable Drive Worm
How it spreads Copies itself via USB drives and external storage. Runs automatically via autorun.inf when a drive is plugged in.
What it does Hides all your folders and files using Windows Hidden/System attributes and creates .lnk shortcuts in their place.
Where it hides %APPDATA%, %TEMP%, Recycle Bin folders, and adds itself to Windows registry startup keys to run on every boot.
Known variants VBS/Autorun.K, Worm.VBS.Dinihou, RavMon.exe, New Folder.exe, USB Virus, Folder.exe worm
.lnk shortcuts autorun.inf hidden files registry persistence VBS worm USB spreading

Manual PowerShell Instructions
Run this in PowerShell as Administrator if you prefer
# Run in PowerShell as Administrator:

Set-ExecutionPolicy Bypass -Scope Process -Force

# Remove autorun.inf from all drives
Get-PSDrive -PSProvider FileSystem | ForEach-Object {
    Remove-Item "$($_.Root)autorun.inf" -Force -ErrorAction SilentlyContinue
    Get-ChildItem $_.Root -Filter "*.lnk" -Force | Where-Object { $_.Name -notmatch '(?i)desktop\.ini' } | Remove-Item -Force
    if ($_.Root -ne "$env:SystemDrive\\") {
        cmd /c "attrib -H -S /S /D \`"$($_.Root)*\`""
    }
}

# Kill suspicious wscript from Temp
Get-Process wscript,cscript -ErrorAction SilentlyContinue |
  Where-Object { $_.Path -match 'Temp|AppData' } |
  Stop-Process -Force
